## 모듈
: 함수, 변수, 클래스 등 모아 놓은 하나의 파이썬 파일(.py)  
: 다른 프로그램에서 가져와 사용 가능(재사용)  
- 표준 모듈(내장 모듈) : 파이썬에 기본 포함 (os, sys, math, random)
- 써드파티 모듈 : 제 3자가 만들어서 제공  
  설치를 먼저 해야 함  
  (numpy, padas, matplotlib)
- 사용자 정의 모듈  
    : 모듈과 사용자 실행 파일이 동일 디렉토리에 위치해야 함 - 아니면 path 지정해줘야함

> *path 지정하는 법*  
> *sys.path.append('module_절대경로')*
> os.path.expanduser("경로") : 사용자 정의 모듈 경로
> 
  
## 모듈 만들기
```py
# 외부에서 수정한 모듈 자동으로 다시 불러오기
%reload_ext autoreload
%autoreload 2 #import된 모든 모듈 자동으로 다시 로드
```
## %%writefile
: vscode에서 사용할 때 주석 사용 X
```py
%%writefile module_name.py

import module_name as m
```

## if \_\_name\_\_ == "\_\_main\_\_":
: 파일이 직접 실행(예를 들어 python module.py)될 때만 특정 코드 실행하게 해주는 조건문  
: 터미널 환경이나 python 명령어 이용하면 \_\_name\_\_ 변수에는 \_\_main\_\_ 값 저장됨  
: 다른 파일에서 이 파일 가져와 사용할 때 (import) \_\_name\_\_변수에는 모듈 이름 저장됨  
: 모듈을 모듈이 아닌 실행 파일로 취급할건지 묻는 것과 동일.  
: 테스트용 코드와 라이브러리 코드 구분
