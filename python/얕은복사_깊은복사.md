## 얕은 복사 깊은 복사

### 얕은 복사
: 바깥 객체만 새로 만들고, 안쪽 객체는 공유  
: 내부 요소는 원본과 연결됨 (같은 주소)  
: list.copy(), copy.copy()
```py
import copy
a=[[1,2],[3,4]]
b=copy.copy(a)
b[0][0]=99
print(a) # [[99, 2], [3, 4]] 원본도 바뀜
print(b) # [[99, 2], [3, 4]]
```

### 깊은 복사
: 바깥 객체, 안쪽 객체 전부 새로 복사  
: 내부 요소도 완전히 분리됨  
: 완전히 독립된 복사본  
: copy.deepcopy()
```py
import copy
a=[[1,2],[3,4]]
b=copy.deepcopy(a)

b[0][0] = 99
print(a) # [[1, 2], [3, 4]] 원본 안 바뀜
print(b) # [[99, 2], [3, 4]]
```
