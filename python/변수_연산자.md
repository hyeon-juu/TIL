## 파이썬 변수
: 값을 저장하기 위한 메모리 공간  
(실제 메모리 사용이 아닌 그 공간 지시하는 변수명에 변수 할당)  
자료형 미리 지정할 필요 없음 (할당되는 값에 따라 자동으로 결정됨)  
> *변수명 = 변수값*

## 파이썬 연산자
- 산술 연산자
```python
a = 5
b = 2

print(a + b)    # 7
print(a - b)    # 3
print(a * b)    # 10
print(a / b)    # 2.5
print(a // b)   # 2 -> 몫
print(a % b)    # 1 -> 나머지
print(a ** b)   # 25
```

- 비교 연산자 
  - ==: 같다
  - !=: 다르다
  - \>: 크다
  - <: 작다
  - \>=: 크거나 같다
  - <=: 작거나 같다
  
- 논리 연산자
    - and: 논리 곱
    - or: 논리 합
    - not: 논리 부정
```python
#10이 2보다 크고 8이 4보다 큰 동시에 7이 3보다 크지 않은지 비교하고, 결과를 출력
print(10>2 and 8>4 and not 7>3)
```
- 할당 연산자
    - = : 오른쪽 값을 왼쪽에 대입
    - += : 왼쪽 값에 오른쪽 값을 더해 왼쪽 피연산자에 대입
    - -=
    - *=
    - /=

- 식별 연산자
    - is : 두 변수가 같은 객체 가리키는지 확인
    - is not : 두 변수가 다른 객체 가리키는지
    - 두 변수에 id() 함수 -> 결과가 같은지 아닌지 

```python
# 가변 객체 리스트는 동일한 값이어도 메모리 관리 따로 함
a = [1,2,3]
b = [1,2,3]
print(a is b) #False
print(id(a)==id(b)) #False (주소 값 반환)

# 불변 객체(immutable)인 문자열 -> 메모리 효율성 위해 동일한 값을 가진 불변 객체 재사용함
string1 = 'hello'
string2 = 'hello'
print(string1 is string2) # True
print(id(string1) == id(string2)) # True
```

- 멤버 연산자
    - in : 왼쪽 값이 오른쪽에 속하는지 확인
    - not in : 왼쪽 값이 오른쪽에 속하지 않는지 확인
```python
# dictionary
# key 값이 있는지 찾음
dict_ = {1:'one', 2:'two', 3:'three'}
print(100 in dict_) # False
```
