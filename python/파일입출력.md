## open()
: 파일 입출력에 사용하는 기본 함수  
: 프로그램과 파일 연결하는 내장함수  
> *파일객체 = open( '파일명' , 모드 )*

### 모드 (읽기, 쓰기, 추가)
> *r : 읽기 모드*  
> *w : 쓰기 모드 - 파일 새로 만들고 내용 씀*  
> *a : 추가 모드 - 만들어져 있는 파일의 끝에 새로운 내용 추가*

### 파일 포인터
- 파일을 가르킴
- 파일을 연 후, 이름표를 달아 해당 파일에 쓰거나, 읽거나, 추가하는 데 활용
- 보통 fp라는 이름 사용

```py
# _는 파이썬에서 실제로 사용하지 않을 변수명을 나타낼 때 사용하는 관례적인 이름

```
```py
# 파일 쓰기 모드 열기
with open("file_name.txt", 'a') as f:
    for _ in range(3):
        f.write("cheer up!!\n")
# with문을 사용할 경우 open을 사용하고 자동으로 닫아줌
```
## read()
: 파일 전체 내용을 하나의 문자열로 만들어서 return값으로 전달
```py
f = open('file_name.txt', 'r')

text = f.read()
print(text)

f.close()

# ================================

with open('file_name.txt', 'r') as fp:
    text = fp.read()
    print(text)
```
```py
# 파일의 라인별로 내용 읽기
f = open('file_name.txt', 'r')

for line in f:
    print(line)

f.close()

# ================================

with open('file_name.txt', 'r') as fp:
    for line in fp:
        print(line)
```
## readline()
: 파일의 전체 내용에서 한 줄 씩 읽어오기  
: 다음 줄 읽으려면 다시 호출  
: 인수로 읽을 문자 수 지정 가능
```py
f = open('file_name.txt', 'r')

for _ in range(5):
    print(f.readline())

f.close()
```
## readline()
: 파일의 전체 내용 한 번에 리스트로 읽어옴  
: 줄바꿈 기준으로 문자열 나눔  
```py
f = open('file_name.txt', 'r')

str_list = f.readlines()
print(str_list)

# ================================

print(list(map(lambda x: x.strip(), str_list)))

f.close()

# ================================
# string.split('\n')
f = open('file_name.txt', 'r')
texts = f.read()

result_list = texts.split('\n')
print(result_list)

# ================================
#파일의 숫자를 읽어와 모두 더한 결과를 출력
f = open('numbers.txt', 'r')
sum = 0
str_list=f.readlines()
for i in str_list:
    sum += int(i)
f.close()
print(sum)
# ================================
f = open('numbers.txt', 'r')
sum = 0
for line in f: # 라인별로 가져옴
    sum += int(line)
f.close()
print(sum)
```
## 파일 내용 추가하기(open()의 'a'모드)
: 이미 만들어져 있는 파일 이름과 일치하는 파일 이름을 지정해야 함  
: 일치하는 파일 없다면 자동으로 쓰기 모드로 열림
```py
f = open('file_name.txt', 'a')

f.write('add_content1\n')
f.write('add_content2\n')

f.close()
```
