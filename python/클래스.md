## 객체 지향 프로그래밍
- 객체(Object) : 속성과 메서드 가질 수 있음  
  클래스에 의해 정의됨
- 클래스(Class) : 객체를 생성하기 위한 설계도 역할 
속성과 속성 처리 위한 메서드 정의
- 인스턴스(Instance) : 클래스를 기반으로 생성된 객체  
고유한 속성, 메서드 가질 수 있음
- 다형성(Polymorphism) : 같은 이름 메서드가 다른 객체에서 다르게 동작할 수 있게 하는 기능(overriding)
- 캡슐화(Encapsulation) : 속성, 메서드를 하나로 묶음
- 추상화(Abstraction) : 복잡한 시스템을 단순화하여 중요한 부분만 노출
- 상속(Inheritance) 

## 클래스
: 여러 객체 동시에 만들어 함수보다 효율적  
: 클래스는 똑같은 무언가 계속 만들어 낼 수 있는 것  
: 클래스로 만들어진 결과물 = 객체  
: 만들어진 객체는 독립적

## __init\_\_ 클래스 생성자
: 객체 생성될 때 자동으로 호출되는 메서드  
: self 클래스 = 객체 자신 (기본 파라미터)
```py
class Room:
    def __init__(self,a,b):
        self.a = a
        self.b = b
        self.print = f'{a} 그리고 {b}'

roomm = Room('hello','world')
print(roomm) # 객체의 메모리 주소를 보여줌
print(roomm.a)
print(roomm.b)
print(roomm.print)
```
## __call\_\_ 클래스 메서드
: 클래스 객체를 함수처럼 사용할 수 있는 메서드
```py
class Room:
    def __init__(self,a,b):
        self.a = a
        self.b = b
        self.print = f'{a} 그리고 {b}'
    def __call__(self):
        print('hi')
    def test(self):
        print("test")

roomm = Room('hello','world')
roomm() # 이렇게 사용 가능
roomm.text() # __call__ 아닌 메서드
```
## __str\_\_ 클래스 메서드
: 객체 print 했을 때 출력
```py
class Test:
    def __init__(self,a):
        self.a = a
    def __str__(self):
        return f"test {self.a}"
print(Test('hello')) # test hello
print(str(Test('hello'))) 
print(Test('hello').__str__())
```

## 상속
: 다른 클래스의 기능을 물려받아 생성
> *class Class_name(상속받을 Class_name)*


## 오버라이딩
: 상속 받은 애 바꿈  
: 부모 클래스에 있는 메서드를 동일한 이름으로 다시 만드는 것
```py
class Room:
    def __init__(self,a,b):
        self.a = a
        self.b = b

class Room_ov(Room): # 상속 받음
    def __init__(self, a):
        self.a = a
        self.b = "b" # overriding
```
## super()
: 부모 클래스 메서드 호출  
: 자식이 오버라이딩 하면 부모클래스의 동일 메서드 사용 불가능 -> super()사용하면 가능
```py
class Pa:
    def hobby(self):
        print("what")
class Ch(Pa):
    def hobby(self):
        print("is")
        super().hobby()
h = Ch()
h.hobby()
```
