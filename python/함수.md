## 매개변수, 인자(인수)
매개변수 : 함수 정의할 때 데이터 받는 부분 (parameter)  
인자 : 함수 호출할 때 데이터 주는 부분(argument)

## 매개변수 default value
: 인자 입력하지 않아도 기본으로 설정된 값 호출
```py
def func(a='hello'):
    return a
```

# 입력한 수 제곱

list(map(sq,[4]))[0]

## 가변 길이 인수
: 임의의 개수 인자 전달 가능  
: 함수에서 파라미터 개수 지정 안해도 됨  
- 위치 가변 길이 인수
  >*args (type = tuple)
- 키워드 가변 길이 인수
  > **kwargs (key-value로 구성된 매개변수를 dictionary로 받아 사용)
```py
# 위치 가변 길이 인수
def cal(*args):
    total = 0
    for n in args:
        total += n
    return total
result = cal(1,2,3,4) # 10

def intro(*args):
    return f'{args[0]} is {args[1]}.' # 순서대로 들어감
```
```py
# 키워드 가변 길이 인수
def d(**kwargs):
    for key, value in kwargs.items():
        print(f'{key} : {value}')
# name="kim", age=30 형태로 입력
# dictionary 인자로 넣으면 에러
# **dictionary 이런식으로 풀어서 입력해야 함
```
## lambda
: 이름 없이 정의된 작은 함수
> lambda 매개변수 : 표현식

```py
# map 함수는 iterable 객체로 반환하기 때문에 list나 tuple로 감싸줘야 함
list(map(lambda x,y:x*y, [1,2,3],[1,2,3]))
# [1, 4, 9]
```
## filter()
: iterable에서 조건 만족하는 요소만 필터링  
: tuple, list로 감싸줘야 함
```py
list(filter(None, [1, 0, 3]))
# None이거나 False인 값 제외
# [1,3]
```
## 재귀함수
: 함수 내에서 자기 자신 호출
```py
def fibonacci(n):
    if n <= 1:
        return n
    else:
        return fibonacci(n-1) + fibonacci(n-2)
```
