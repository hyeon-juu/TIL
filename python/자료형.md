## 딕셔너리 dictionary
: key - value 구조  
: key 이용해 value 찾음
```python
dic = {'name':'kim', 'age': 1000, 'color':'red'}
```
```python
# dict()
# 이중 리스트나 이중 튜플 모두 다 됨 
# 내부 리스트에 2개의 요소가 들어가 있으면 됨.
tup = ((1, '서울'), (2, '대전'), (3, '대구'), (4, '부산'))

dic = dict(tup) 
print(dic) # {1: '서울', 2: '대전', '광역시': '대구', 4: '부산'}
```
```python
# 리스트 컴프레헨션을 이용한 dict 변수 할당
# 튜플은 양 괄호 생략 가능
dic1 = dict((i, i**2) for i in range(5))
dic2 = dict([(i, i**2) for i in range(5)])
# {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
```
```python
# value 수정하기
dic[1] = '구미'
print(dic) # {1: '구미', 2: '대전', 3: '대구', 4: '부산'}

# value 추가하기
dic[10] = '서울' # {1: '구미', 2: '대전', 3: '대구', 4: '부산', 10: '서울'}
```
```python
# dict 메서드
# items(), keys(), values()
# 이 메서드 적용 후, list(), tuple()로 wrapping 해줘야 함
print(dic.keys()) 
# dict_keys([1, 2, 3, 4, 10])
print(dic.values()) 
# dict_values(['구미', '대전', '대구', '부산', '서울'])
print(dic.items()) 
# dict_items([(1, '구미'), (2, '대전'), (3, '대구'), (4, '부산'), (10, '서울')])
```
```python
for key, value in dic.items():
    print(f'{key}: {value}')
# 1: 구미
# 2: 대전
# 3: 대구
# 4: 부산
# 10: 서울
```

## 셋 set
: 집합 연산 처리 위한 자료형  
: 중복 허용하지 않음  
: 순서 고려하지 않음  
: 리스트는 셋의 요소가 될 수 없음(가변 객체 안됨)  
: 인덱싱, 슬라이싱 불가능함
```python
s = {0, 1, 2, 'hi', 'good'}
```
```python
# 집합 메서드
# add : 요소 추가
# discard : 요소 삭제 (하나씩이며 튜플이나 셋 형태로 여러 개 삭제 불가능)

# update : 여러 요소 한꺼번에 추가하기(set으로 묶어야 요소 온전히 입력됨)
fav = {'sky', 'air'}
fav.update('river', {'soil', 0, 1})
# {0, 1, 'e', 'sky', 'sea', 'i', 'v', 'air', 'soil', 'r'}

# pop : random하게 요소 추출됨
```
```python
# 합(|), 교(&), 차(-), 대칭차(^)
sa = {1,2,3,4,5,6}
sb = {1,2,3,6,7,8}

print(sa | sb) 
# {1, 2, 3, 4, 5, 6, 7, 8}
print(sa & sb)
# {1, 2, 3, 6}
print(sa - sb)
# {4, 5}
print(sa ^ sb)
# {4, 5, 7, 8}
```
```python
# 부분집합 확인
# <=, >=
print({4,5,6} <= sa) # True
print({4,5,6} >= sa) # False
```


```py

```
```py
# format
name = 'jason'
age = 1200.0005

print('{}'.format('hello'))
# hello
print('hello, 내 이름은 {}이고, 나이는 {}살이야.'.format(name, age))
# hello, 내 이름은 jason이고, 나이는 1200.0005살이야.
print('hello, 내 이름은 {}이고, 나이는 {:.1f}살이야.'.format(name, age))
# hello, 내 이름은 jason이고, 나이는 1200.0살이야.
```
