## 연관 배열
: 딕셔너리 = 연관 배열 구현해놓은 것  
: 고유한 키 사용해 키, 값 쌍 저장하는 추상 데이터 타입  
: 해시 테이블은 연관 배열을 구현한 자료구조  

## 해시 테이블
: 고유한 키 사용해 키-값 저장하는 선형 자료구조  
: 삽입, 삭제, 탐색 -> O(1) -> 대용량 데이터 다룰 때 효율적  
> ***해시 함수*** : 키를 배열의 인덱스로 변환하는 함수(해시 함수가 반환하는 인덱스)  
> ***해시 충돌*** : 서로 다른 키가 같은 인덱스 매핑되는 경우(두 숫자의 해시값이 같을 경우)  

> 충돌 해결 방법
> - 체이닝  
> : 같은 인덱스에 여러 개 데이터 LinkedList로 저장하여 포인터 연결  
> : 충돌 발생 시, 해당 인덱스의 리스트에 데이터 추가(배열)  
> - 오픈 어드레싱  
> : 다음 빈 슬롯(인덱스) 찾아 저장  
> 대표적으로 선형 탐사 
>

## 문자 열 속 문자 수 세기 
```py
def count(str_):
  dict_ = {}
  for i in str_:
    if i in dict_:
      dict_[i] += 1
    else:
      dict_[i] = 1
  print(dict_)
count("helllo")
```

# dictionary
def two_sum(list_,target):
  dict_ = {}
  for index, num in enumerate(list_):
    rem = target - num

    if rem in dict_:
      return index, dict_[rem]
    else:
      dict_[num] = index
list_ = [7, 7, 3, -1, 6, 7, 15]
two_sum(list_, 14)
