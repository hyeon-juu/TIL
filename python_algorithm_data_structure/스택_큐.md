## 스택
: 가장 최근에 추가한 요소만 접근, 제거 가능  
: 선형 자료구조  
: LIFO (Last In First Out)  
: 접근이 제한된 자료구조(반드시 순서 따라야 함)  
: push, pop, peek  
- 제한된 스택 : 추가할 수 있는 요소 수 제한 O  
- 무제한 스택 : 추가할 수 있는 요소 수 제한 X

## 스택 사용
: push, pop -> O(1)  
: 전체에 접근 -> O(n)


## 스택 구현
```py
class Stack:
  def __init__(self):
    self.items = []

  def push(self,data):
    self.items.append(data)

  def pop(self):
    return self.items.pop()

  def size(self):
    return len(self.items)
  
  def is_empty(self):
    return len(self.items) == 0

  def peek(self):
    return self.items[-1]
```

## 최소 스택
: 가장 작은 요소 반환
```py
class MinStack():
  def __init__(self):
    self.main = []
    self.min = []
  
  def push(self, n):
    if len(self.main) == 0:
      self.min.append(n)

    elif n <= self.min[-1]:
      self.min.append(n)
      
    else:
      self.min.append(self.min[-1])
    self.main.append(n)
  
  def pop(self):
    self.min.pop()
    return self.main.pop()
  
  def get_min(self):
    return self.min[-1]

st = MinStack()
st.push(10)
st.push(15)
st.push(-10)
print(st.main)
print(st.min)
```

## 큐
: 가장 먼저 들어온 요소부터 접근, 제거 가능  
: 추상 선혀 자료구조  
: FIFO ( First In First Out )
- enqueue : 큐 뒤에 요소 추가
- dequeue : 큐 앞에 요소 제거하여 반환
- front/peek : 앞 요소 조회
- size, is_empty

## 큐 구현
```py
class Node:
  def __init__(self,data,next=None):
    self.data = data
    self.next = next
class Queue:
  def __init__(self):
    self.front = None
    self.rear = None
    self._size = 0
  def enqueue(self,item):
    self._size += 1
    node = Node(item)
    if self.rear is None:
      self.front = node
      self.rear = node
    else:
      self.rear.next = node
      self.rear = node
  def dequeue(self):
    if self.front is None:
      raise IndexError('pop from empty queue')
    self._size -= 1
    temp = self.front
    self.front = self.front.next
    if self.front is None:
      self.rear = None
    return temp.data
  def size(self):
    return self._size

queue = Queue()
queue.enqueue(1)
queue.enqueue(2)
queue.enqueue(3)

for _ in range(queue.size()):
    print(f"dequeue : {queue.dequeue()} len : {queue.size()}")
```
