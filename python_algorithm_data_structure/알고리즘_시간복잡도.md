## 알고리즘
: 문제를 해결하기 위한 절차나 규칙의 집합  
: 문제 해결 위해 수행해야 할 단계별 명령의 순서  
: input이 주어졌을 때 원하는 output 얻기 위한 일련의 절차  

### 시간복잡도
: 입력의 크기(n) 커질 때 알고리즘이 얼마나 빠르게 실행되는 지

### 공간복잡도
: 알고리즘이 추가로 사용하는 메모리 공간의 양

## Big-O
: n이 커짐에 따라 알고리즘이 얼마나 느려지는지(시간), 얼마나 많은 메모리 쓰는지(공간)'를 차수의 크기(입력 크기 n이 커질 때 알고리즘 실행 횟수가 얼마나 급격히 늘어나는가)로 표현하는 방법

### 상수 시간 알고리즘 O(1)
: n 크기에 관계없이 동일한 단계만 필요한 경우  
: 가장 효율적인 알고리즘
### 로그 시간 알고리즘 O(log n)
: n에 대해 실행 시간이 log n에 비례하는 알고리즘  
: 문제 크기 절반씩 줄여가며 해결 -> 대규모 데이터 다룰 때 효과적  
: 이진탐색, 이진 힙, 분할정복 정렬 등  
### 선형 시간 알고리즘 O(n)
: 실행시간이 직선적으로 증가 = 데이터 2배 늘어나면 실행시간도 2배 늘어남  
: 모든 입력 요소 한 번 씩 확인해야 하는 경우 많음

### 선형 로그 시간 알고리즘 O(n log n)
: 모든 원소를 확인(O(n))과 그 안에서 반복적으로 절반 줄이는 과정(O(log n)) 결합
### 2차 시간 알고리즘 O(n²)
: 이중 반복문(중첩 루프)이 모든 쌍/조합 검사할 때 발생( 두 개의 인덱스(i,j)로 모든 쌍 비교, 버블 정렬처럼 인접 원소 반복 비교)
### 지수 시간 알고리즘 O(c^n)
: 최악의 시간 복잡도

## 공간 복잡도
: 메모리를 얼마나 사용하는지 나타냄
- 고정 공간 : 프로그램 자체가 차지하는 메모리
- 자료구조 공간 : 데이터 세트, 예를 들어 탐색 대상이 되는 리스트 저장하는 데 필요한 메모리
- 임시 공간 : 중간 처리 위해 사용하는 메모리
