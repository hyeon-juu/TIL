## 자료구조
: 자료(data)를 효율적으로 저장하고 관리하며 활용하기 위한 방법  
: 어떻게 저장하고 검색, 삽입, 삭제 할 지 ..

### 추상 vs 구현 데이터 타입
- 추상 데이터 타입  
  : 자료구조를 설명하는 데이터 타입  
  : 무엇을 할 수 있는가?에 초점  
   : 동작 방식 정의(인터페이스)  
  : 스택(LIFO), 큐, 리스트, 트리, 해시맵 등

- 구현 데이터 타입
  : 어떻게 구현되었는가?에 초점  
  : 실제 메모리에 저장하고 동작하도록 만든 구체적 방법  
  : 배열, 연결 리스트, 힙, 트리 노드 구조 등  
  : 실제 구현 방식(코드, 구조체)

### 선형 vs 비선형 자료구조
- 선형 자료구조
  : 데이터가 일렬로 나열되는 구조  
  : 각 원소가 앞 뒤 순차적으로 한 줄 연결  
  : 기본적으로 순차 탐색, 인덱스로 빠르게 접근 가능  
  : 배열, 리스트, 스택(LIFO), 큐(FIFO)

- 비선형 자료구조  
  : 계층적, 관계형 구조(가지 뻗는 구조)  
  : 데이터 여러 방향으로 연결(트리/그래프 형태)  
  : 특정 조건 따라 탐색  
  : 트리, 그래프, 힙

### 정적 vs 동적 자료구조
- 정적 자료구조  
  : 크기, 메모리 공간이 컴파일 시점에 고정되는 구조  
  : 크기는 고정되어 바꿀 수 없지만, 저장된 데이터 값은 바꿀 수 있음  
  : 배열, 고정 크기 행렬

- 동적 자료구조  
  : 크기, 메모리 공간이 실행 시점에 유동적으로 변할 수 있는 구조  
  : 저장해야 할 데이터 양 특정할 수 없, 필요할 때마다 동적 할당  
  : 파이썬 배열, 연결 리스트, 스택, 큐, 트리, 그래프

## Linked List 연결 리스트  
: 추상 데이터 타입  
: 배열은 메모리에 연속적으로 데이터 저장, but 연결 리스트는 인덱스 없고 연속적인 메모리 블록에 저장 X  
: 대신 노드의 체인 저장
> 노드 : 데이터 보관하는 필드와 다음 노드 위치나타내는 포인터로 이뤄짐   
> 연결 리스트 첫 번째 노드 : 헤드  
> 마지막 노드 : 테일 (None을 가리키는 포인터 포함)  

: 요소 삽입 - > 다른 데이터 밀어내지 않고 포인터 두 개만 수정하면 됨

## Linked List 종류
 - 단순 링크드 리스트  
  : 각 노드에서 다음 요소 가리키는 포인터만 존재  
  헤드에서 마지막 향해 이동하는 것 외 할 수 있는 것 없음
 - 이중 링크드 리스트  
  : 각 노드에서 다음 요소 가리키는 포인터, 이전 요소 가리키는 포인터 모두 존재  
  : 양 방향 이동 가능(이전 노드로도 이동 가능)  
- 원형 링크드 리스트  
  : 마지막 노드에 첫 번째 노드를 가리키는 포인터 존재 -> 시작과 끝 명확하지 않음(순환)

## Linked List 성능
- 접근  
  : 순차적 이동 -> O(n)  
  : 배열은 인덱스로 접근 -> O(1)
- 탐색  
  : 처음부터 끝까지 탐색 -> O(n)  
  : 배열 일반 탐색 O(n), 정렬된 배열은 이진탐색 가능 -> O(log n)
- 삽입  
  : 포인터만 바꿔주면 됨 -> O(1)  
  : but 위치 찾는 데 O(n) 걸릴 수 있음  
  : 배열은 삽입하면 원소 한 칸 씩 밀림 -> O(n)
- 삭제  
  : 포인터 연결만 바꿔주면 됨 -> O(1)  
  : but 위치 찾는 데 O(n) 걸릴 수 있음  
  : 배열은 원소들 당겨야 함 -> O(n)
- 메모리 효율   
  : 노드마다 데이터 + 포인터(주소) 저장해야해서 배열(값만 저장)보다 메모리 더 많이 차지함

## Linked List 사용
- 삽입 / 삭제 자주 발생할 때
- 데이터 크기 자주 변할 때
- 메모리 공간 연속적이지 않을 때
- 큐 / 스택
  
## Linked List 만들기
: Deque 사용하여 링크드 리스트 효율성 이용 가능 
```py
class Node:
  def __init__(self, data, next=None):
    self.data = data
    self.next = next # 다음 노드를 가지는 포인터
class LinkedList:
  def __init__(self):
    self.head = None # 아직 아무 노드 없으면 None
  def append(self, data):
    if not self.head: # 아직 아무 노드도 없으면
      self.head = Node(data) # 첫 번째 노드
      return
    current = self.head
    while current.next:
      current = current.next # 끝까지 이동
    current.next = Node(data) # 마지막에 새 노드 연결
#처음에는 head에 노드 연결하고, 그 다음부터는 마지막 노드 찾아서 이어붙임

  def __str__(self):
    node = self.head
    while node is not None:
      print(node.data)
      node = node.next
    return 'end'
a_list = LinkedList()
a_list.append('a')
a_list.append('b')
print(a_list)
```

## Linked List 노드 제거
: 이전 노드의 포인터를 수정하여 삭제할 노드를 가리키지 않도록 변경
```py
def remove(self,target):
  if self.head is None: # 빈 리스트일 경우
    return 
  if self.head.data == target: # head 노드가 삭제 대상일 경우 next 노드를 head노드로 변경
    self.head = self.head.next
    return
  prev = self.head
  current = self.head.next
  while current:
    if current.data == target:
      prev.next = current.next # 이전 노드의 포인터를 삭제할 노드의 다음 노드의 포인터와 같게 함
      return
    prev = current
    current = current.next
```

## Linked List 뒤집기
: 순회하면서 현재 노드와 이전 노드를 변수에 저장, 현재 노드가 이전 노드를 가리키도록 바꿈
```py
def reverse(self):
  if self.head is None:
    return
  current = self.head
  previous = None
  while current:
    next = current.next
    current.next = previous
    previous = current
    current = next
  self.head = previous
```
